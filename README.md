# 💬 Flirty Chatbot App

A playful React + TailwindCSS chatbot with personality.  
It features:
- 🎭 Tone shifting (soft & sweet vs bold & cheeky)
- 🔄 Cooldown system (avoids repeating twists/teases)
- 🧠 Memory (prevents repeating fallback lines too soon)
- ✨ Messenger‑style UI with avatars, bubbles, and timestamps

---

## 🚀 Quick Start

Clone the repo (or click **Use this template** on GitHub):

```bash
git clone https://github.com/yourusername/flirty-chatbot
cd flirty-chatbot
npm install
npm start
